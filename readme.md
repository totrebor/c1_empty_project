### Microsoft Windows Only

1. copy c1_empty to c1_puppo
2. edit update_mapod_generic.cmd, remove REM and update rclone paths
3. run update_mapod_generic.cmd from c1_puppo directory (you need to have a MAPOD4D Framework correctly configured)
4. /main/mapod_metaverse array add BaseRasMapodElement
